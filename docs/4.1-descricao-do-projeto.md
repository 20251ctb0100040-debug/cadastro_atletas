## O problema, na voz do cliente
"O cadastro de atletas é um sistema para facilitar o cadastro e a listagem dos atletas, deixando as informações mais organizadas e fáceis de consultar." (Cliente)

<!-- Uma a três frases, do jeito que o cliente falou, entre aspas. Depois das aspas, o papel dele entre parênteses. -->

> _"Preciso de um sistema para facilitar minha vida no cadastro de atletas para os jogos estudantis do IFPR." (Cliente)

## Propósito

<!-- Conte como o problema acontece hoje e que sistema é este. Duas ou três frases bastam.
     Tela, botão, cor e aplicativo não entram aqui. Isso é solução, e a solução vem depois. -->

_O sistema Cadastro de Atletas será utilizado para organizar as informações dos atletas que participarão dos jogos estudantis do IFPR. Atualmente, o cadastro pode ser feito de forma manual, dificultando a organização e a consulta dos dados dos participantes.._

## Objetivo

<!-- O que vai ser verdade quando o sistema estiver funcionando. Escreva de um jeito que o cliente consiga conferir.
     "Melhorar a organização" ninguém confere. "Nenhuma encomenda entregue no dia errado" o cliente confere na primeira semana. -->

_O objetivo é permitir que os responsáveis cadastrem e consultem os atletas de forma organizada, mantendo as informações dos participantes disponíveis para os jogos estudantis do IFPR.._

## Quem usa

<!-- Escreva papéis, não pessoas. Para cada perfil, diga o que ele faz no sistema.
     Se quem pediu o sistema não usa nenhum dos perfis, conte isso numa frase à parte. -->

- **Administrador/Responsável pelo cadastro 1.** _Cadastra, altera, exclui e consulta as informações dos atletas._
- **Responsável pelos jogos.2.** _Consulta os dados dos atletas cadastrados para organizar a participação nos jogos._

## Escopo

<!-- O que o sistema faz. De 4 a 6 itens, cada um com um verbo. -->

- O sistema cadastra os atletas.._
- O sistema lista os atletas cadastrados._
- O sistema consulta as informações dos atletas._
- O sistema exclui atletas cadastrados._
- 
## Fora do escopo

<!-- Pelo menos 2 itens, cada um com o porquê. Item sem porquê parece esquecimento. Com o porquê, vira decisão. -->

- _Controle de resultados dos jogos, porque o sistema será focado no cadastro e gerenciamento dos atletas._
- _Inscrição automática em competições, porque a finalidade do sistema é organizar os dados dos atletas, e não realizar inscrições em competições._

## Características principais

<!-- Onde o sistema funciona, quem pode mexer em quê e o que precisa ser rápido ou seguro.
     Dê número sempre que der, como "em menos de três segundos".
     Escopo é o que o sistema faz. Característica é como ele faz. Não repita o escopo aqui. -->

_O sistema deverá ser simples e fácil de utilizar, permitindo que o responsável pelo cadastro encontre as informações dos atletas de forma rápida. Os dados deverão ficar organizados em um único sistema, com acesso às funções de cadastro, consulta, alteração e exclusão.._
