# 4.1 Descrição do Projeto

## O problema, na voz do cliente

"Preciso de um sistema para organizar o cadastro dos atletas e suas modalidades nos Jogos Estudantis do IFPR, pois atualmente faço esse processo manualmente. Isso dificulta a organização das informações, a consulta dos participantes e a identificação dos atletas inscritos em cada modalidade, principalmente durante a preparação dos jogos."

(Carlos, responsável pela organização dos Jogos Estudantis do IFPR)

## Propósito

O sistema Cadastro de Atletas será utilizado para organizar as informações dos participantes dos Jogos Estudantis do IFPR. Atualmente, o cadastro é realizado de forma manual, dificultando a organização dos atletas e das modalidades esportivas. O sistema permitirá manter os dados dos atletas, das modalidades, das inscrições e dos resultados organizados em um único lugar.

## Objetivo

O objetivo é facilitar a organização dos Jogos Estudantis do IFPR, permitindo o cadastro, a edição, a exclusão e a consulta dos atletas. O sistema também permitirá que os atletas visualizem seus próprios dados, realizem inscrições nas modalidades e consultem os resultados. Além disso, a Comissão Organizadora poderá gerenciar as modalidades e definir as regras dos jogos.

## Quem usa

**Administrador:** responsável por cadastrar, editar, excluir e consultar as informações dos atletas, mantendo os registros organizados e atualizados.

**Atleta:** poderá visualizar seus próprios dados, inscrever-se nas modalidades disponíveis e consultar os resultados dos jogos.

**Comissão Organizadora:** responsável por gerenciar as modalidades esportivas e definir as regras dos Jogos Estudantis do IFPR.

## Escopo

- O sistema permite cadastrar atletas participantes dos Jogos Estudantis do IFPR.
- O sistema permite editar as informações dos atletas cadastrados.
- O sistema permite excluir registros de atletas.
- O sistema permite consultar os atletas cadastrados.
- O sistema valida os dados informados antes de salvar as alterações.
- O sistema armazena as informações cadastradas.
- O sistema permite gerenciar as modalidades esportivas.
- O sistema permite definir as regras dos jogos.
- O sistema permite que os atletas visualizem seus próprios dados.
- O sistema permite que os atletas realizem inscrições nas modalidades.
- O sistema disponibiliza as informações necessárias para as inscrições.
- O sistema permite consultar os resultados dos jogos.

## Fora do escopo

- **Inscrição automática em competições externas:** ficará de fora porque o sistema será destinado às inscrições nas modalidades dos Jogos Estudantis do IFPR.
- **Organização de competições externas:** ficará de fora porque o sistema será utilizado somente para auxiliar na organização dos jogos do IFPR.
- **Realização automática das partidas:** ficará de fora porque o sistema terá como objetivo organizar as informações dos participantes, das modalidades e dos jogos, não sendo responsável pela realização das competições.

## Características principais

O sistema deverá apresentar uma interface simples e organizada, facilitando o acesso às informações dos atletas e das modalidades. Deverá permitir que o Administrador cadastre, edite, exclua e consulte os dados dos participantes. Os atletas poderão visualizar seus próprios dados, realizar inscrições nas modalidades e consultar os resultados. A Comissão Organizadora poderá gerenciar as modalidades e definir as regras dos jogos. As informações deverão permanecer organizadas e armazenadas corretamente, evitando a perda de registros.
