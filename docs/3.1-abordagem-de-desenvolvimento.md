# 3.1 Abordagem de Desenvolvimento


O projeto será desenvolvido por etapas, utilizando ideias do Scrum. Primeiro, serão definidos os requisitos do sistema. Depois, será criado o banco de dados e serão desenvolvidas as telas de cadastro dos atletas. Em seguida, serão implementadas as funções de consulta, edição e exclusão dos dados. Por último, serão realizados testes para verificar se todas as funcionalidades estão funcionando corretamente.


Ao final de cada etapa, será feita uma revisão do que foi desenvolvido, verificando se os requisitos estão sendo atendidos e se as partes do sistema estão funcionando em conjunto. As alterações e atualizações do projeto serão registradas no repositório para manter o histórico do desenvolvimento. Cada parte concluída poderá ser apresentada ao responsável pelo projeto para receber sugestões e realizar possíveis melhorias.



Essa abordagem foi escolhida por permitir que o sistema seja desenvolvido gradualmente, facilitando a identificação e a correção de erros durante o processo. Diferentemente do modelo em cascata, em que as etapas seguem uma sequência mais rígida, a utilização de ideias do Scrum permite revisar e melhorar o sistema ao longo do desenvolvimento. Como o projeto será realizado individualmente, não serão utilizadas todas as práticas do Scrum, como reuniões diárias e divisão de tarefas entre equipes.
