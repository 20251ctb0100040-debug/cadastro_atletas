# 3.1 Abordagem de Desenvolvimento

O projeto será desenvolvido de forma incremental, utilizando ideias do Scrum. Inicialmente, serão definidos os requisitos do sistema e identificadas as funcionalidades necessárias. Em seguida, serão desenvolvidas as funções de cadastro, edição, exclusão e consulta dos atletas. Depois, serão implementadas as funcionalidades de gerenciamento de modalidades, inscrição dos atletas, definição das regras dos jogos e consulta dos resultados.

Ao final de cada etapa, será realizada uma revisão para verificar se as funcionalidades desenvolvidas estão de acordo com os requisitos definidos. Também serão realizados testes para identificar possíveis erros e garantir que as partes do sistema funcionem corretamente. As alterações e atualizações serão registradas no repositório do projeto.

Essa abordagem foi escolhida por permitir que o sistema seja desenvolvido gradualmente, facilitando a identificação e a correção de erros durante o processo. Como o projeto será realizado individualmente, serão utilizadas apenas algumas práticas do Scrum, sem a necessidade de reuniões diárias ou divisão de tarefas entre equipes.
