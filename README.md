Cadastro de Atletas — organização dos participantes dos Jogos Estudantis do IFPR

Projeto Integrador de Análise e Projeto de Sistemas, 2026.
IFPR, Centro de Referência Ponta Grossa. Técnico em Informática Integrado ao Ensino Médio.

Autoria: Luis Gustavo Pereira Melo , como aparece no AVA.

Cliente: [Carlos], responsável pela organização dos Jogos Estudantis do IFPR.

Apresentação do projeto

O Cadastro de Atletas é um sistema desenvolvido para auxiliar o responsável pela organização dos Jogos Estudantis do IFPR. Atualmente, o cadastro dos participantes é realizado de forma manual, dificultando a organização das informações e a identificação dos atletas inscritos em cada modalidade. O sistema permitirá cadastrar e consultar atletas, organizar as modalidades esportivas e relacionar os participantes às modalidades em que irão competir. Dessa forma, será possível manter as informações organizadas e facilitar o trabalho de preparação dos jogos.

Como este repositório funciona

Cada seção do documento mora num arquivo dentro de "docs/", com o número do modelo do IFPR no nome. Não renomeie esses arquivos. É pelo nome que as seções são encontradas na hora da correção.

As seções entram uma por aula. Enquanto a vez de uma seção não chega, o arquivo dela mostra um cadeado 🔒. Na aula, o molde chega pelo AVA junto com a mesma seção pronta do BiblioTech.

Os diagramas vão para "diagramas/", sempre em dois arquivos com o mesmo nome. O ".drawio" serve para editar, e o ".png" aparece na página. As telas do protótipo vão para "prototipos/".

O exemplo do BiblioTech

A pasta ""exemplo-bibliotech/"" (exemplo-bibliotech/) tem as seções do BiblioTech já resolvidas, com os mesmos nomes de arquivo do seu "docs/". Quando travar, abra a seção do BiblioTech ao lado da sua e pergunte o que foi feito naquele ponto.

O exemplo cresce a cada aula no "repositório do modelo" (https://github.com/Profe-Berssa-IFPR/2026-APS-modelo/tree/main/exemplo-bibliotech). A cópia que veio para o seu repositório para na seção que existia no dia em que você o criou. Para ver as seções novas, é lá que você olha.
